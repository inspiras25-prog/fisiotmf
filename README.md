# Site TMF — Thaís de Medeiros Figueiredo

Loja dos cinco materiais digitais e kit completo. Versão com capas corrigidas.

## Enviar ao GitHub
1. Descompacte este ZIP.
2. Envie os arquivos que estão dentro dele para a raiz do repositório.
3. O arquivo index.html deve aparecer diretamente na raiz.

## Publicar no Cloudflare Pages
Conecte o repositório do GitHub e selecione a branch principal.
- Framework preset: None
- Build command: exit 0
- Build output directory: .

Não é necessário instalar dependências. As imagens estão incorporadas no HTML.
As fontes do Google são carregadas pela internet.

## Compras e contato
Esta versão envia os pedidos para o WhatsApp configurado em window.TMF_CONFIG, no início do index.html. Confira o número antes de divulgar.
Pagamento e entrega dos PDFs são combinados pelo WhatsApp. Não há cobrança ou entrega automática integrada; os links de checkout estão vazios.
Não coloque os PDFs vendidos no repositório público.

Os preços e os conteúdos do site original foram preservados.
